# Алгоритм и блок-схема 

Алгоритм:

1. Начало.
2. Ввод данных: Считать с клавиатуры значения координат точки x и y.
3. Проверить условия границ фигуры (переключатель условий / множественный if-else):
	• Если y < 1  вывести на экран «НЕ ПРИНАДЛЕЖИТ области».
	• Если y > 5  вывести на экран «НЕ ПРИНАДЛЕЖИТ области».
	• Если (2 * x - y + 9) < 0  вывести на экран «НЕ ПРИНАДЛЕЖИТ области».
	• Если (2 * x + y - 13) > 0  вывести на экран «НЕ ПРИНАДЛЕЖИТ области».
	• Во всех остальных случаях (когда все четыре условия выполнены успешно) вывести на экран «ПРИНАДЛЕЖИТ области».
